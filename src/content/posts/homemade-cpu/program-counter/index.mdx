The Program Counter keeps track of which instruction should be run next. A single 74LS161 counter is used for this task.

The chip also allows an inital value to be set with input pins A thorugh D. Both T and P pins must be enabled for the counter to run.

The counter was placed to the right of the bus interface, the four outputs tied so the counter value can be uploaded to the bus. The green jumper wire determines the upload enable. LEDs indicate counter value.

Hooking Pin 2 up to the clock, the counter starts, overflowing back to `0000` after `1111`. Now the CPU will run instructions 0 through 15 repeatedly. The usage of a 4-bit counter limits the size of the program this CPU can run to 16 bytes, which is quite small.
